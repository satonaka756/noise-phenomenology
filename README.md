# Noise Phenomenology
## ノイズ現象論

> 乱れのなかに、構造を見る。

---

## 概要

本リポジトリは、ノイズ現象を出発点として、
フラクタル、数学、哲学、精神分析などを横断して考察する
一連の研究を収録するためのアーカイブです。

ここでいう「ノイズ」は、単なるランダムな雑音ではなく、
既存の構造から外れたもの、あるいは構造の境界に現れる
現象を含む広い概念として扱います。

---

## Research

### 1. ノイズ現象論
ノイズ現象そのものの構造と、その生成・変形・回復について考察する。


### 2. フラクタル
自己相似性、階層構造、局所と全体の関係について考察する。

### 3. 停止核・Recovery
停止、回復、閉包などの概念を数学的に定式化する。

### 4. ゼータ関数・Euler積
局所構造から大域的構造がどのように生成されるかを考察する。

### 5. 哲学
構造、差異、生成、連続性、主体などをめぐる哲学的考察。

### 6. 精神分析
自由連想、抵抗、転移などを、ノイズ現象論との関係から考察する。

## Method

本研究では、既存の理論体系に現象を当てはめることよりも、
現象のなかに生じる「ずれ」「乱れ」「抵抗」「反復」から
構造を記述することを重視する。
